# 안양 청년정책 AI 리서치 비서 — 서비스 소개

## Summary

흩어진 안양시 청년정책 공지를 대신 챙겨 보고, 나에게 필요한 것만 골라 대화로 설명해
주고, 새 소식은 내가 정한 시간에 알려 주는 개인 비서 웹앱이다.

이 문서는 개발 진행 상태·기술 세부가 아니라 **서비스 자체**를 비개발자 관점에서
설명하는 소개 문서다. 기술 세부는 [[anyang-youth-policy-assistant]]의 "설계 문서" 절을 본다.

## Context

가독성 있는 소개 자료가 필요하다는 요청으로 만들었다. 같은 내용을 페이지
(`서비스-소개.html`, 같은 폴더)로도 제공한다. 기능 범위의 근거는 [[anyang-service-scope]].

이런 분께 맞는다:

- 공지가 너무 많아 무엇이 나에게 해당되는지 모르겠는 분
- 게시판을 매번 들어가 확인하기 번거로운 분
- 궁금한 정책을 검색 대신 편하게 물어보고 싶은 분

## Details

### 왜 만들었나 — 찾아다니던 정보를, 찾아오는 정보로

- **지금까지**: 청년정책 공지는 양이 많고 흩어져 있어, 내 나이·상황에 맞는 것을 찾으려면
  게시판을 일일이 뒤져야 했다.
- **이 서비스로**: 비서가 매일 게시판을 확인해 두고, 물어보면 근거 공지와 함께 답하고,
  관심 있을 만한 새 공지는 알림으로 먼저 알려 준다.

### 이용 순서 (처음 쓰는 날)

1. **가입** — 구글 계정 또는 이메일
2. **동의** — 개인정보 이용과 해외 전송에 각각 동의
3. **프로필** — 생년·성별·직군·재학/재직 여부 4가지만
4. **대화 · 알림** — 궁금한 것을 묻고, 알림 받을 시각을 정하기

### 주요 기능

| 기능 | 설명 |
|---|---|
| AI에게 물어보기 | 편하게 물으면 내 나이대·상황에 맞춰 공지를 찾아 설명 |
| 근거 공지 카드 | 답변 위에 참고한 공지가 카드로 붙고, 누르면 공지 상세(원문 링크)로 이동 |
| 나에게 맞는 공지 목록 | 관심사에 가까운 공지 모음, 상세 내용과 원문 링크 |
| 새 공지 알림 | 알림 시각 자유 설정·켜기/끄기, 휴대폰 푸시로 수신 |
| AI가 기억하는 내 정보 | 대화에서 파악한 관심사를 보고, 고치고, 지우기 |
| 대화 기록 · 탈퇴 | 지난 대화 목록 보기, 언제든 계정 탈퇴 |

> **알아 두기**: 추천과 알림은 **대화에서 쌓인 관심사**를 기준으로 고른다. 프로필(나이대 등)은
> 채팅 답변을 맞출 때 쓴다. 아직 대화를 하지 않았다면 목록은 최신순으로 보이고 알림은 오지
> 않는다. 대화를 할수록 더 잘 맞춰진다.

### 자동화 — 내가 잠든 사이에 일어나는 일

매일 새벽 게시판을 스크랩해 두고, 각자 부탁한 시간에 맞춰 "이거 관심 있으실 것 같아요"
하고 알려 주는 비서를 떠올리면 된다. 사람이 버튼을 누르지 않아도 아래 일이 매일 반복된다.

| 언제 | 무엇을 |
|---|---|
| 매일 04:00 | **공지 수집** — 안양시 청년 게시판에서 새로 올라오거나 바뀐 공지를 가져온다 |
| 수집 직후 | **내용 읽어 두기** — AI가 새 공지를 읽고 무슨 내용인지 기록해 둔다. 공지가 수정되면 다시 읽는다 |
| 5분마다 | **알림 시각 확인** — 알림 받을 시각이 된 사람을 확인한다. 알림은 정한 시각에서 늦어도 5분 안에 도착 |
| 내 알림 시각 | **맞춤 알림 발송** — 관심사와 가까운 새 공지만 보낸다. 알림을 켠 뒤 올라온 공지만, 같은 공지는 한 번만 |
| 90일 후 | **오래된 기록 정리** — 수집 이력·AI 사용량 같은 운영 기록을 자동으로 지우도록 준비되어 있다 |

### 개인정보 — 내 정보는 이렇게 다룬다

- 이름·이메일·계정 같은 신원정보는 외부 AI에 보내지 않는다. AI에는 나이대 같은 조건과
  공지 내용만 전달된다.
- 대화 속 전화번호·이메일·주민등록번호 형태는 AI에 보내기 전에 자동으로 가린다.
- 가입할 때 "개인정보 수집·이용"과 "해외 전송"(대화 내용을 AI가 처리)을 따로
  동의받고, 처리방침이 바뀌면 다시 동의를 받는다.
- 비밀번호는 8자 이상, 15분 안에 5번 넘게 틀리면 잠시 로그인이 막힌다.

### 관리자 화면 (운영자용)

지정된 관리자 계정만 들어갈 수 있다. 관리자도 개인의 대화 내용이나 기억 원문은 볼 수 없고,
숫자로 모은 통계만 본다.

| 화면 | 하는 일 |
|---|---|
| 공지 수집 관리 | 수집 실행 이력·실패 확인, 수동 수집, 잘못 들어온 공지 숨기기 |
| 알림 발송 현황 | 날짜별 발송·실패 수, 알림 구독 수 |
| 사용자 관리·통계 | 가입자 수, 연령대·직군 분포, 계정 정지·삭제 |
| AI 사용량 | 대화 AI·내용 분석 AI 호출 수, 무료 한도 대비 사용량, 오류 현황 |

### 이용 형태

휴대폰 홈 화면에 앱처럼 추가해 쓸 수 있는 웹앱(PWA)이다. 별도 앱 설치 없이 웹 주소로 바로 쓴다.
