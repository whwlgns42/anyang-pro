# Lint Prompt

```text
이 Obsidian AI 업무 위키를 lint 해줘.

규칙이나 에이전트 설정의 충돌 검토도 포함되면 .claude/rules/knowledge-ops.md의 규칙 검토 절을
따라서, 기준 문서(rule-review-baseline)를 먼저 읽고 그 문서에 없는 새 항목만 보고해줘.

먼저 `bash scripts/lint-wiki.sh`를 실행해줘.

FAIL로 나오는 것(깨진 링크, frontmatter 오류, 문서명 중복, index.md의 죽은 링크,
규칙 중복 서술, 매니페스트 불일치)은 먼저 고쳐줘.

WARN으로 나오는 것(단방향 링크, 고아 문서, superseded 참조, type과 폴더 불일치)은
하나씩 판단해서 고칠지 그대로 둘지 알려줘. 항목이 많으면 `--all`로 전체를 봐줘.

그다음 기계가 못 잡는 것을 사람 판단으로 점검해줘.

1. raw 원본이 수정되었거나 wiki 영역에 섞여 있지 않은가?
2. 중요한 wiki 문서가 index.md에 누락되어 있지 않은가?
3. 중요한 작업이 log.md에 기록되어 있지 않은가?
4. 저장의 5가지 필터를 통과하지 못한 일회성 정보가 wiki에 저장되어 있지 않은가?
5. 민감정보, API 키, 토큰, 고객 개인정보가 저장되어 있지 않은가?

추가로 Karpathy 원칙 정렬을 점검해줘.

6. 같은 주제의 문서들 사이에 모순되는 내용이 있는가? (예: 같은 결정에 대해 다른 근거 기술)
7. 실제로 지난 달 이상 아무도 참조하지 않은 "고아 페이지"가 있는가? (backlinks 없음)
8. 진부한 정보나 이미 바뀐 결정을 반영하지 않은 개념 문서가 있는가?

문제가 있으면 파일별로 수정 제안을 정리해줘. 고아 페이지는 삭제할지 통합할지 제안해줘.
```
