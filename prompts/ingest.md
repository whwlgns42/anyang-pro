# Ingest Prompt

```text
AI-Sessions/raw/에 추가된 자료를 ingest 해줘.

raw 원본은 절대 수정하지 말고, 내용을 읽은 뒤 다음을 수행해줘.

1. wiki/sources/에 출처 요약 문서를 만들어.
2. 반복해서 쓸 개념은 wiki/concepts/에 새로 만들거나 기존 페이지를 업데이트해.
3. 중요한 결정이나 판단이 있으면 wiki/decisions/에 문서를 만들어.
4. 기존 wiki 페이지들을 검토해서 이 자료와 연결되는 교차 참조(backlink)를 추가해. 단순 요약이 아니라 지식 체계에 통합하는 게 목표야.
5. 실패 사례나 다시 하면 안 되는 내용이 있으면 wiki/errors/에 저장해.

작업이 끝나면 index.md와 log.md를 갱신해줘. 어느 기존 문서를 업데이트했는지 명시해줘.
```
