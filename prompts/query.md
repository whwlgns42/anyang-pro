# Query Prompt

```text
옵시디언을 참조해서 이전 작업 맥락을 복원해줘.

먼저 index.md와 log.md를 확인하고, 관련 wiki 문서를 찾아서 다음을 정리해줘.

1. 핵심 맥락 (누가, 무엇을, 왜)
2. 이전에 내린 결정사항과 근거 (decisions/)
3. 아직 남은 액션과 블로킹 요소
4. 관련 개념과 용어 정의 (concepts/)

이어진 작업이 의미 있는 결과물이 되면, 그 결과를 wiki에 저장해. 특히 새로 학습한 개념, 의사결정, 리스크는 반드시 저장하도록 해. 이렇게 하면 매번 원문 재검색 없이 컴파일된 지식 체계가 계속 커져.
```
